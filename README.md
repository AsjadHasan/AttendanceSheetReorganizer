# AttendanceSheetReorganizer
Ask a teacher for the number of students and the number of days, then for each student ask for their attendance as a comma-separated list (1 = present, 0 = absent) across the days. Print the reorganized view where each day lists which students were present.

Nested for loop,
Lists,

List indexing,
if condition,

2D list / nested list,

👉 Nested loops + Lists + String processing
